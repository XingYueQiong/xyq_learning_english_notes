# xyq_learning_english_notes

这是一个个人英语学习笔记仓库，只保留学习内容本身。

## 目录结构

```text
Grammar/            语法笔记
Sentence/           句子理解
Word/               单词、短语记录
Listen/             听力相关内容
2026_daily_record/  每日学习记录
```

## 使用方式

直接在对应目录下维护 Markdown 或纯文本笔记即可。

如果要一次性提交并推送当前所有改动，直接运行根目录下的 `一键提交.bat` 即可。
执行时会先在当天的 `2026_daily_record` 日文件末尾自动补上未来复习日期，再提交并推送全部改动。

## 说明

- `Grammar/` 和 `Sentence/` 主要记录语法和句子理解。
- `Word/` 记录单词、短语和表达。
- `Listen/` 存放听力相关内容。
- `2026_daily_record/` 按日期记录每天的学习内容。
